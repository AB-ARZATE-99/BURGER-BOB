# 🍔 Burger Bob - Proyecto de Interactividad con CSS

¡Bienvenido al repositorio del sitio web interactivo para **Burger Bob**! Este proyecto fue desarrollado utilizando exclusivamente **HTML5** y **CSS3** para mejorar la experiencia visual y la retroalimentación del usuario.

## 🚀 Enlace del Sitio en Vivo
Puedes ver el resultado final funcionando en tiempo real aquí:
(https://ab-arzate-99.github.io/BURGER-BOB/)

---

## 🛠️ Tareas Resueltas

### 🎯 Escenario 1: Retroalimentación Visual
* **Tarea 1 (:hover):** Al pasar el mouse sobre el texto *"¡VEN A BURGER TOWN!"*, este cambia de color, aumenta su tamaño un 10% de forma suave y el cursor se convierte en pointer (manita).
* **Tarea 2 (:active):** Al mantener presionado el botón *"¡BURGER TOWN!"*, cambia a un color más oscuro y se encoge ligeramente simulando un efecto de botón hundido.

### 🍟 Escenario 2: Contenido Visual Avanzado
* **Tarea 3 (Estilos de Imagen):** Se integró la imagen de la hamburguesa justo debajo de su encabezado, configurada con un ancho máximo, bordes redondeados y perfectamente centrada en la pantalla.
* **Tarea 4 (:target):** Al hacer clic en la palabra *"¡ARROZ!"*, se activa un enlace de anclaje que cambia automáticamente el color del título de la hamburguesa sin usar JavaScript.

---

## 💻 Tecnologías Utilizadas
* **HTML5** - Estructura semántica del sitio.
* **CSS3** - Pseudo-clases (`:hover`, `:active`, `:target`), transiciones suaves y maquetación (márgenes automáticos y bloques).
